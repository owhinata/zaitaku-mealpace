## 分かったこと

- `deps` の `pip install` がシステムの Python で止まる。Ubuntu の Python 3.12 は PEP 668 で
  `externally-managed-environment` を返す。リポジトリ直下に `.venv` を作り、
  `-DPYTHON3=$PWD/.venv/bin/python3` を渡して回避した。`CMakeLists.txt` の
  `find_program(PYTHON3 ...)` はキャッシュに値があれば探索を飛ばすので、
  `CMakeLists.txt` 本体の変更は要らなかった。README とコメントに手順を足した。
- README の手順に `deps` が無く、初見では通らなかった。README を直した。
- ボードコアの取得に約 110 MB のダウンロードが要る（`arm-none-eabi-gcc` が 95 MB）。初回は数分かかる。
- `firmware/logger` は無修正でコンパイルが通る。ビルド時の警告も出ていない。
- グローバル変数が RAM の 37%。大半は mbed OS とシリアルのバッファと思われる（未確認）。
  M2 で推論を載せるときに残りを見る必要がある。

# 0007 `tools/record.py` の出力先は `data/raw/` に固定する

日付: 2026-09-20　状態: 採用

## 決定

- `tools/record.py` から `--out` を廃止する。出力先はスクリプトの位置から解決したリポジトリの
  `data/raw/` とし、実行時の cwd にも引数にも依存させない。
- `data/sample/` の見本（`self`、10秒以内）は、`data/raw/` から手でコピーして置く。
- `p1` の記録先は M3 の前に決める（`docs/plan.md`「M3 の前に行うこと」）。リポジトリごと
  暗号化ディスクに置くか、`p1` だけリポジトリ外の場所を必須にする。

## 理由

- M0 の関門レビュー（#6）の指摘。`--out` が任意のパスを受け、subject の検査は `self` / `p1` の
  列挙だけだったので、`--subject p1 --out data/sample` で、`.gitignore` が再包含する場所
  （`!data/sample/**`）へ生データを直接記録できた。
- 出力先を変える必要のある作業が、今の計画に無い。

## 塞がっていない経路

- `git add -f data/raw/...` と、記録したファイルを手で `data/sample/` に移す操作。git の側に
  検査（pre-commit など）は置いていない。
- 出力先がリポジトリの中なので、`p1` の生データを「ローカルの暗号化ディスクにのみ置く」
  （CLAUDE.md）を満たすかどうかは、リポジトリを置くディスクで決まる。上の通り M3 の前に決める。

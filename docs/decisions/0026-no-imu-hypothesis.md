# 0026 咽喉マイク版は IMU なしで始め、M3 の分岐点の合格線に届かなければ LSM6DSOX を足す（仮説）

日付: 2026-10-02　状態: 採用（仮説。M3 で確かめる）

人が 10/2 に決めた（決定 5。引き継ぐ範囲と再試験の時期は 10/2 夜の人の決定）。構造は docs/decisions/0002 と同じ（第一候補で始め、合格線に届かなければ次を足す）。構成は docs/decisions/0025。
`docs/evaluation.md` は書き換えていない。この記録は、0019 が「評価の定義からの逸脱に当たる。進む前に記録を書く」とした経路（`docs/evaluation.md` 8 行目の
特徴量の指定から IMU を外す）を、咽喉マイク版について記録するもの。

## 決定

- 咽喉マイク版は IMU なしで始める（仮説: 咽喉マイクの音だけで M3 の分岐点の合格線に届く）。
- 判定: 咽喉マイクの音だけの特徴量（`docs/evaluation.md` 8 行目の音の並び: MFCC 13 次元、スペクトル重心、ゼロ交差率）で、`docs/evaluation.md` の M1 分岐点の
  合格線（手作り特徴量＋ロジスティック回帰、検出率 70% 以上、誤検出 3 回/分以下、セッション単位の分割、評価 3 セッション以上、混同行列とセッション一覧）を、
  `self` の新しい記録で確かめる。M3 の判定基準の (3)（docs/decisions/0024）。
- 届かなければ、Qwiic 接続の LSM6DSOX を足して再試験する。結合は docs/decisions/0019 の形（窓ごとの特徴量ベクトル 1 本）。IMU の特徴量は
  docs/decisions/0012 の 14 次元（`docs/evaluation.md` 8 行目の IMU の並び）。そのときは 8 行目の指定をそのまま当てる。
- IMU を足した再試験は M3 の中（〜10/25）で行う（人の決定）。そのため、LSM6DSOX（Qwiic）を音だけの結果を待たずに先に手配しておく必要がある。
  手元にあるか、発注するかは人の作業で、10/2 の時点で未確認。
- IMU なしで評価する間は、`docs/evaluation.md` 8 行目の「IMU（振幅、RMS、ピーク数、主軸方向）＋」を咽喉マイク版について外して読む。窓・数え方・分割・合格線は
  変えない。8 行目は書き換えない。

### M1 の IMU 側データを引き継ぐ、の範囲

- M1 の 28 セッションは Nano RP2040 Connect 基板の LSM6DSOX と PDM マイクで録った。咽喉マイクの音と同時には録っていない。
  そのため、咽喉マイクの音と IMU を 1 本の特徴量ベクトルにする分類器（0019 の形）の学習・評価には使えない。
- 引き継ぐもの: IMU の特徴量の定義（0012 の 14 次元）と計算のコード（`analysis/features.py` の IMU の部分、`firmware/bench/` の案3）、#20 の知見
  （IMU は `water`、音は `saliva` を拾う。役割が分かれる）、M1 の数字（比較の基準。docs/decisions/0017）。
- LSM6DSOX を足したら、咽喉マイクと同時に `self` を録り直す。基板の取り付け（Nano の基板ごと喉元）と外付けの取り付けは違うので、M1 の IMU の数字と
  そのまま比べない。

## 理由

- 第一候補で始め、合格線に届かなければ次を足す（0002 と同じ構造）。部品と配線を最小にして M3 の日程に入れる。
- 参考: M1 の評価側で、基板の PDM マイクの音だけでは検出率 0.435、IMU だけでは 0.464、両方で 0.783 だった（docs/decisions/0017「M2 への課題」の 3）。
  これは基板のマイクの数字で、咽喉マイクの音には当てはまらない。音だけで届かない可能性は残るので、この決定は仮説として置く。

## 選ばなかった案

- **最初から LSM6DSOX を足す。** 音だけで足りるかが分からなくなり、配線と取り付けが増える。
- **Nano RP2040 Connect を IMU 用に併用する。** 2 つの基板の時刻合わせが要る。

## 確かめていないこと

- 咽喉マイクの音だけで M1 分岐点の合格線に届くか（M3 で確かめる）。
- LSM6DSOX（Qwiic）が手元にあるか、発注が要るか（人。10/2 の時点で未確認）。
- UNO Q のどちら側（MCU 側か Linux 側か）で読むか。読むときのサンプリング周波数（M1 は 104 Hz）。
- 音だけで届かなかった場合に、IMU を足した再試験（同時の録り直しを含む）が M3 の期間（〜10/25）に収まるか。

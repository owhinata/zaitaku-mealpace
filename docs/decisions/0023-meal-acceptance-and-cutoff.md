# 0023 M2 の通し記録（`meal`）は `s` の打ち忘れ・打ち遅れで捨てず、2026-10-04 で打ち切る

日付: 2026-10-02　状態: 採用

#27 の `meal`（`docs/recording-protocol.md`「M2 の通し記録（`meal`）」、#26）の採否の規則、`s` の押し方、記録を止める規則を変える。人が決めた。
`docs/evaluation.md` の定義（窓、イベント単位の数え方、非嚥下区間、3 セッション以上、合格線）は変えていない。`analysis/`・`tools/`・`firmware/` も変えていない。
M1 の記録手順（`docs/recording-protocol.md` の M1 の節）は変えていない。経緯は Issue #27 のコメントにある。

## 決定

### `s` の押し方

- `meal` の `s` は、食べ物・飲み物を意識して飲み込んだときに押す。無意識の小さな唾液の嚥下は押せなくてよい。押した `s` は唾液の嚥下でもそのまま残す。
- 打ち忘れ・打ち遅れに気づいても `o` の note（`missed s`・`late s`）は求めない。Ctrl-C の直後、ほかの出力を見る前に、打ち忘れの体感と打ち遅れの体感を
  それぞれ「ほぼ無し / 数回 / 多い」の 3 段でログの集計表に書く。体感は採否に使わない。

### 捨てる条件（#27 の `meal` の全セッションに当てる）

次のどれかに当たるセッションは、フォルダごと消して録り直す（打ち切りの前に限る）。

1. `tools/check_session.py` の取りこぼし（窓の飛び）が 1% 以上。
2. `tools/record.py` の XOR 不一致が 0 でない。
3. `detect.csv`・`feat.csv` の `t_ms` か `window_t_ms` に逆行がある、または隣との差が 1000 ms を超える。
4. 窓の終端からの送信の遅れの最大が 1000 ms を超える（docs/decisions/0021 の上限）。
5. 記録の始まり（`detect.csv` の最初の `window_t_ms`）より前のマーカーがある（docs/decisions/0011）。
6. 終わりの 1.5 秒以内に `s` がある（30 分の自動終了で切れた場合を含む）。
7. `meta.json` の `fw` が `detector` でない。
8. 会話ありで、`conv` の note が前後の空白を除いてちょうど `conv` でない。
9. `o` の `wrong key` が `s` に関わる（嚥下でないのに `s` を押した、または `s` の代わりに別のキーを押した）。

`s` の打ち忘れと打ち遅れでは捨てない。採否は今までどおり、陽性（`positive`・`prob`・`led`）と `analysis/evaluate_detector.py` の出力を見ずに決める。

### 打ち切り

- 2026-10-04 の終わりまでに録り（フォルダ名の日付が `20261004` 以前）、上の捨てる条件に当たらなかった `meal` の全部で記録を打ち切る。それより後に延ばさない。
- `docs/recording-protocol.md` の「3 セッション以上、合計 `s` 50 以上、会話なし 1・会話あり 1、収集日 2 日以上」に届かなくても延ばさない。届かなかった条件は「未達」として #28 に渡す。
- 打ち切りまでの採用セッションは全部評価の対象に入れる（後から選んで外さない）。ただし途中で装置に書き込んだ場合は、plan #27 第 8 節のとおり、それより前の `meal` を「書き換え前。M2 の数字に使わない」として `data/raw/` に残し、対象に入れない。
- 打ち切ったら、続けて評価を実行し、数字を log に貼って #28 に渡すところまでを #27 で行う（録りっぱなしで終わらせない）。
- 3 セッション以上なら合算（M2 の数字）を出す。3 セッション未満なら、`docs/evaluation.md`「評価には 3 セッション以上」を満たさないので、M2 の合算と合格線との比較は出さない。
  `evaluate_detector.py` を `--sessions` で全採用セッションを挙げて走らせ、セッションごとの数字を「M2 の合算は未達で出せない」と明記して報告する（1 本でも同じ）。採用が 0 本なら評価は
  走らせず、「採用 0 本。数字なし」と報告する。
- 2026-10-05 以降は `meal` を録らない。録ってしまった `meal` は `data/raw/` に残して評価に使わない（消さない。参考値にも入れない）。集計表に「打ち切りの後。M2 の数字に使わない」と書く。10/5 以降の `meal` がある、または途中で装置に書き込んだときは、評価は打ち切りまでに録った書き込み後の採用分の全部を `--sessions` で明示して走らせる（`--sessions` は必須。既定の対象は `self` の `meal` を日付も書き込みの履歴も見ずに全部拾う）。両方が起きた場合も、指定するのは打ち切りまでに録った書き込み後の採用分だけ。

## 数字の読み方（#27 の報告に書く）

- `s` は本人が押せた嚥下だけで、食事中のすべての嚥下ではない。`docs/evaluation.md` の検出率の分母は「マーカーを打った嚥下」なので、定義の文言どおりに数えている。
  「50 口」は押せた嚥下（`s`）の合計で、口に運んだ回数でも、食事中の嚥下の総数でもない。
- 打ち忘れた嚥下は、定義の上で非嚥下区間に入る。欠けた `s` で誤検出の回数は増えうるが、非嚥下区間の分も伸びるので、率のずれの向きと大きさは確定できない。
- 押せた嚥下が、はっきりした（検出しやすい）嚥下に偏っていれば、検出率は高めに出るおそれがある。打ち遅れは、陽性窓が `s` の区間から外れれば検出率を下げ誤検出を増やしうるが、
  陽性窓が嚥下の開始に対してどこに出るかは確かめていない。どちらも向きと大きさは確定できない。
- 集計表の体感の 3 段は、読むときの材料で、補正には使わない。
- #22 の収集日4 の参考値（M1 の手順。すべての嚥下に `s` を押す決まり）とは `s` の決まりが違うので、並べるときはそう書く。

## 理由

- 食事中は咀嚼と飲み込みが続き、唾液の嚥下を含めてすべてに `s` を押すことは本人にもできない（1 本目で人が申告）。今の規則のままでは採用できる `meal` が
  ほとんど残らない。
- 打ち忘れで捨てる規則は、打ち忘れによる数字のずれを避けるためのもので、評価の定義そのものの要件ではない（定義は「マーカーを打った嚥下」で数える）。
- `missed s`・`late s` の note は、食べながら打つには入力が長く、打てた分だけが残る（打ち忘れ・打ち遅れの数を表さない）。note を条件にすると、打たないほうが採用されやすくなる。
  体感の 3 段のほうが毎回同じように書ける。
- 打ち切り: 今のセンサとモデルが合格線に届かない場合の次の手（代替センサの試用。#28 の選択肢）に早く移るため。日付だけで決まる規則で、陽性を見る前に決めた。

## 1 本目（`20261002-203031_self_meal`）の扱い

- 規則の変更の前に、#26 の決まり（唾液を含めてすべての嚥下に `s` を押す）で録った。人は打ち忘れが多かったと申告した（体感「多い」）。今までの規則なら捨てる。
- 規則の変更は、1 本目の記録と採否の材料（`record.py` の表示、`check_session.py`、`accept_check.py`。どれも陽性を出さない）を見た後、陽性を誰も見ず、
  `evaluate_detector.py` を走らせる前に、#27 の全セッションに当てる規則として決めた。
- 変更後の捨てる条件のどれにも当たらないので採用する。変更後の規則に照らして 1 本目だけを外すことはしない。
- 1 本目と 2 本目以降で `s` の決まりが違う（1 本目はすべての嚥下を狙った、2 本目以降は意識した食べ物・飲み物の嚥下）。集計表の列「記録時の `s` の決まり」に書く。

## 選ばなかった案

- **今の規則のまま捨てる。** 同じ申告が続く見込みで、M2 の数字が出せない。
- **1 本目だけ例外で採用する。** 規則が 1 本ごとに変わり、セッションを選んだ形になる。
- **打ち忘れの数を後から `events.csv` に足す、または時刻を推定する。** 生の計測データの書き換えになる。時刻の根拠も無い。
- **`missed s`・`late s` の note の数でセッションを捨てる。** note を打たないほうが採用されやすくなる。
- **評価の定義（非嚥下区間）から打ち忘れの分を除く。** 打ち忘れた時刻が残らないので実装できず、`docs/evaluation.md` を変えることになる。
- **打ち切りを設けず、条件（3 セッション・50・会話の両方・2 日）に届くまで録る（plan #27 の R2）。** 次の手に移るのが遅れる。

## 確かめていないこと

- 打ち忘れ・打ち遅れの量と、それによる誤検出率・検出率のずれの向きと大きさ。
- 「意識した嚥下」と「無意識の唾液の嚥下」の境目が、セッションごと・日ごとにどれだけ揺れるか。

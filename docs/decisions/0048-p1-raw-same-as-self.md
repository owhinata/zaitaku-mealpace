# 0048 `p1` の生データは `self` と同じく `data/raw/` に記録する。暗号化ディスクの要件を外す

日付: 2026-11-03　状態: 採用（人の決定 2026-11-03、Issue #55）

docs/decisions/0007 の「`p1` の記録先は M3 の前に決める」（0024 で「本人試用の前」と読む）に答える。
Issue #55 の本文にある 11/1 の決定 (a)（`p1` だけリポジトリの外の暗号化ディスク）は、人が 11/3 に取り消した。
0005（「`p1` は暗号化ディスクのみに置き」）・0007・0028・0042 は当時の記録として書き換えず、暗号化の要件についてはこの記録で読み替える。

## 決定

1. **`p1` の生データは `self` と同じく `data/raw/` に記録する。** `tools/record.py` の出力先の固定（0007。`--out` を置かない、
   `cond` の検査、セッションは `data/raw/` の直下だけ）を `p1` にもそのまま当てる。`record.py` と `analysis/` は変えない。
2. **暗号化ディスクの要件を外す。** CLAUDE.md「データの扱い」の「被験者 `p1` の生データはローカルの暗号化ディスクにのみ置く」と、
   0005 決定 3 の「`p1` は暗号化ディスクのみに置き」は、この記録で外す。CLAUDE.md の該当行は、この記録の後に人が書き換える
   （CLAUDE.md の冒頭の決まり）。AGENTS.md は同じコミットで直す（docs/workflow.md「何を基準にするか」）。
3. **守る規則はそのまま。**
   - コミットしない。`data/raw/` は .gitignore 済みで、出力先はリポジトリの `data/raw/` に固定（0007）。「解析のため一時的に」も不可。
   - `p1` の生データをチャット・Issue・外部サービスに貼らない（Codex のプロンプトにも入れない。AGENTS.md、codex-review skill）。
   - 公開するのは集計値と匿名化した波形の切り出しだけ。`data/sample/` に `p1` の記録を置かない（`data/sample/` の見本は `self` の 10 秒以内）。
   - 日付は「試用 N 日目」の相対表記。続柄は「家族」まで。被験者 ID は `self` と `p1` だけ（CLAUDE.md「公開してよい情報の線引き」）。
   - `p1` の生波形はモデル確定後に削除する（0005 決定 3 の後半。変えない）。
4. **本人試用の前の実装 Issue は作らない。** 記録先のための環境変数、暗号化の確かめ方、`analysis/` の読み口の変更は要らない。
5. この記録で決めないこと: 咽喉マイクの経路（`--throat`、`--unoq-detector`）で `p1` を受けるか（0028 決定 4、0030 決定 8、0025 の追記。
   本人試用の前に別に決める）。本人への説明と同意（`docs/plan.md`「本人試用の前に行うこと」）。

## 理由

- 暗号化ディスクが守っていたのは、PC の紛失・盗難・廃棄のときにディスクから読み出されることだけ。「コミットしない」は
  `.gitignore` と出力先の固定（0007）が、「貼らない」「公開は集計値と匿名化した切り出しのみ」は CLAUDE.md の別の規則が守っていて、
  暗号化の有無に依らない。
- `self` と同じ扱いにすれば、`record.py` と `analysis/` を変えずに済み、記録の手順も `self` と同じになる。本人試用は応募期間の外で
  時期を決めていない（0024）ので、使う当てのないコードと検査を増やさない。
- (a) の形では、環境変数の設定・暗号化の確かめ方・リポジトリ外の検査・`analysis/` の読み口を新しく作り、Codex の plan レビューを
  通す実装の Issue が要った。守れる範囲（紛失・盗難・廃棄）に比べて、作るものが多い。

## 代償（外したことで守れなくなるもの）

- PC の紛失・盗難・廃棄のとき、`data/raw/` の `p1` の生データはディスクから読み出せる（ディスク全体を暗号化していない場合）。
  運用で注意する（PC を手放すときは `data/raw/` を消す）。
- 0007「塞がっていない経路」（`git add -f`、手で `data/sample/` に移す、`data/raw` を別の場所へのシンボリックリンクにする）は、
  `p1` にもそのまま当たる。git の側に検査（pre-commit など）は置かない。

## 記事（#56）の「未検証」に渡す材料

- 「本人試用は未実施。本人のデータは開発者のデータと同じ扱い（リポジトリに入れない、集計値と匿名化した切り出しだけを公開する）と決めた。」

## 検討した他の案

- **(a) `p1` だけリポジトリの外の暗号化ディスク**（11/1 に一度決め、11/3 に取り消し）。環境変数が指すディレクトリにだけ書き、
  未設定・リポジトリの中・暗号化されていない場所なら始めない。上の「理由」の 3 点目のとおり、作るものが多い。
- **(b) リポジトリごと暗号化ディスクに置く。** `record.py` は変えずに済むが、守れているかが clone の場所で決まり、`self` の作業まで
  暗号化ディスクに縛る。

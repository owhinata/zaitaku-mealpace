# 0002 センサ: 第一候補は基板の IMU＋PDM マイク。代替を視野に入れる

日付: 2026-09-19　状態: 採用

## 決定

- 第一候補は Nano RP2040 Connect 搭載の LSM6DSOX（IMU）と MP34DT06JTR（PDM マイク）。追加部品なしで方式の可否を判定する。
- 記録形式に `analog.csv` と `meta.json.sensors` を持たせ、代替センサを後から足せるようにしておく。

## 代替候補

1. 圧電コンタクトマイク（圧電素子＋高インピーダンスバッファ→ADC）
2. ピエゾ電線センサー（ロボセンサー技研）。ピエゾフィルムを芯線に巻いた直径 0.5 mm の同軸ケーブル型。自己発電・無電源、布に織り込める。原理は接触振動の計測で、ネックバンドに縫い込める点が利点。入手性と納期は要確認（問い合わせを準備段階で出す）。

## 切り替えの条件

- M1 分岐点で合格線に届かない場合、まず 1 を追加して再試験。
- 基板マイクが食卓の音に負ける（M2 以降で誤検出が減らない）場合、2 を検討。

## 注意

- 分岐点を代替センサの入手に依存させない。
